# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:
- be respectful and constructive;
- assume good intent;
- no harassment, discrimination or personal attacks;
- never share other people's private media or data.

Report unacceptable behaviour privately to the maintainer via GitHub ([@izhddm](https://github.com/izhddm)), or through the repository's private security reporting if the issue is sensitive. Reports are handled confidentially. The maintainer may remove content or block participants who violate these rules.
